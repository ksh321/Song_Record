# 개발 환경 설정

P01-01은 폴더와 설정 예시만 준비한다. MySQL 컨테이너·포트·영속 볼륨과 서버 연결은 후속 P01 작업에서 구성한다.

1. `.env.example`을 같은 폴더의 `.env`로 복사한다.
2. 두 비밀번호에 서로 다른 로컬 개발용 값을 넣는다. 빈 값 그대로 사용하지 않는다.
3. `.env`는 Git 제외 대상이며 예시 파일만 추적한다.

`.env` 파일은 Spring Boot가 자동으로 읽는다는 의미가 아니다. Compose의 명시적 환경 변수 전달 또는 IDE 실행 환경 변수 설정은 실행 환경 구성 단계에서 연결한다.
앱에서 DB에 직접 접속하지 않는다. DB 데이터·로그를 파일로 만들 경우 `infra/data/`, `infra/logs/`는 Git에서 제외한다.
[기술 버전 기준](../docs/contracts/toolchain-versions.md)을 따르며 실제 이미지·Wrapper·SDK 잠금 검증은 해당 프로젝트 생성 시 기록한다.
