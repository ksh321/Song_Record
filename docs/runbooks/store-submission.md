# P24-09 스토어 제출 준비

2026-10-14 확인. 제출·결제·운영 공개 배포는 이번에 실행하지 않는다. 사용자는 Play 개발자 계정이 없다고 답했다. 새 유료 계정을 만들지 않는다.

## SDK와 마이크

설치 FlutterExtension의 compile/target SDK는36, minSDK24다. 앱은 해당 값으로 구성한다. [Google Play 현재 요구](https://support.google.com/googleplay/android-developer/answer/11926878?hl=en)는 새 모바일 앱 API36 이상이다. 제출 당일 실제 AAB manifest와 최신 정책을 다시 확인한다.

Manifest에는 RECORD_AUDIO, FOREGROUND_SERVICE, FOREGROUND_SERVICE_MICROPHONE와 비공개 RecorderService/microphone 형식이 있다. 사용자 시작·런타임 권한·지속 알림·중지 동작의 P18 실제 기기 근거를 유지한다. [마이크 서비스 제한](https://developer.android.com/develop/background-work/services/fgs/service-types#microphone)에 따라 백그라운드에서 새 마이크 캡처를 임의 시작하지 않는다. Play Console에서 실제 기능 설명·사용자 시작/중지 시연을 제출하며 존재하지 않는 기능을 신고하지 않는다.

## 서명

출시 빌드의 debug 서명 대체를 제거했다. prodRelease 패키징은 업로드 키 미등록이면 명시적으로 실패한다. 검증/debug 앱의 서명과 기존 설치 데이터는 바꾸지 않는다. 업로드 키는 최초 Play 앱 등록 전에 새 전용 키로 만들거나 기존 해당 앱 키를 사용하며, 앱 서명 키와 구분한다.

SONGRECORD_SIGNING_PROPERTIES는 비밀값이 아닌 보호된 로컬 properties의 절대 경로다. 파일에 storeFile/storePassword/keyAlias/keyPassword를 제공한다. 키·암호·파일은 Git 제외 `.local/workflow/release/`에서 Windows 사용자 ACL로 보호하고 빌드 시에만 임시 파일을 만든 뒤 제거한다. 현재 키를 생성하거나 등록하지 않았으므로 서명된 출시 AAB 통과로 기록하지 않는다. Play 계정/앱 존재를 확인하지 않고 기존 키를 덮어쓰거나 재발급하지 않는다.

## 개인정보와 데이터 보안 표시 대조

아래는 코드와 계약에 맞춘 제출 초안이다. [Data safety 공식 안내](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)에 따라 서비스 제공자의 처리를 포함해 실제 출시 연결을 기준으로 최종 선택한다. ‘외부 전송 없음’, ‘음성 수집 없음’, ‘완전 암호화 보장’, ‘즉시 모든 사본 삭제’를 표시하지 않는다.

| 데이터 | 실제 처리와 목적 | 제출 시 확인 |
|---|---|---|
| Google/카카오 제공자 계정 ID·서비스 UUID·기기 UUID/표시명·인증 증명 | 로그인·계정 연결·기기/계정 격리. 서버는 검증된 제공자 ID로 식별하며 이메일로 계정을 합치지 않음 | 사용자 ID·기기/식별자. 현재 코드의 등록 email은null; SDK가 별도 제공하는 정보를 실제 OAuth 설정과 대조 |
| 곡·녹음 제목/메모·태그·플레이리스트·녹음 메타정보 | 로컬 관리·서버 정보 동기화 | 사용자 생성 콘텐츠. 파일 업로드를 하지 않아도 정보 동기화는 별개 |
| 마이크 녹음 파일 | 사용자 녹음 시 로컬 저장, 보관 조건/사용자 동의에 따라 서버 사본 업로드 | 오디오 파일. Google/카카오·Manana에 녹음 파일을 보내는 기능 없음 |
| UUID·작업/결과/시각·성능·저장량·보관 요청 유형 | 운영 장애·보관 수요 집계 | 앱 활동/진단. 실제 재생·오프라인 이용 집계는 아직 미연결; 발급 URL을 실제 재생으로 간주하지 않음 |
| 외부 ZIP·M4A | 사용자가 내보낼 때 사용자가 고른 저장 위치 | 인증/서버 비밀키 제외, 일반 ZIP에는 개인 콘텐츠가 포함됨. 서버가 외부 사본을 회수하지 않음 |

광고·유료 결제·데이터 판매 기능은 현재 구현되지 않았다. Google/카카오 인증, Manana 검색/차트, 서버/MySQL, Cloudflare R2 처리를 각각 공개 표시한다. HTTPS 전송과 운영 백업 인증 암호화는 종단 간 암호화나 모든 관리자 접근 불가의 보장이 아니다. 오프라인/로컬 데이터·자발적 서버 파일 업로드·정보 동기화를 구분한다.

## 삭제와 보관

앱 설정의 계정 탈퇴 및 별도 `web/account-deletion` 경로를 제공한다. [Play 삭제 요구](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en)에 맞춰 실제 공개 HTTPS 삭제 링크·앱 내부 진입·소유 확인·처리 상태를 검사한다. 현재 localhost 웹은 공개 삭제 URL의 증거가 아니다.

요청 접수 시 새 세션/URL/업로드를 차단한다. 진행 중 lease/기발급 URL을 배출하고 객체 부재·DB 제거·백업 부재를 확인한다. 운영 백업 최대7일은 정책 목표이며 장애나 노트북 중단으로 넘으면 경고·재시도하고 삭제 완료로 감추지 않는다. 완료/백업 부재와 접수 후30일 조건으로 최소 확인증/탈퇴 제어 원장을 정리한다. 계정이 살아 있는 동안 영구 삭제 UUID/세대 최소 원장은 재생성 방지를 위해 유지한다. 오프라인 기기는 재연결 때 적용하고 외부 ZIP/M4A는 회수하지 않는다.

## 외부 출처와 남은 공개 설정

Manana의 저장/캐시/재표시 조건은 제공자 확인 미완료다. D12의2026-10-10 사용자 결정으로 무료 서비스 작업 차단은 유예됐고 유료 도입 전 확인 과제를 보존한다. 허가 확보라고 신고하지 않는다. 문의는 미전송.

공개 개인정보처리방침은 앱 이름, 실제 게시자·문의 연락처, 수집/전송/목적/보관/삭제 내용과 위 정책을 포함해야 한다. 게시자·공개 문의 이메일 및 개인정보/삭제 웹 게시 승인이 아직 없다. 이 확인 전에는 초안을 공개하거나 스토어에 제출하지 않는다. Play 계정은 없으므로 실제 제출은 후속 사용자 선택이며 자동 결제하지 않는다.
