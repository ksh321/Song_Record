# 노래기록 개인정보 처리 안내

작성일: 2026-10-14. 게시자 표시: 노래기록 운영자. 문의: happycompanyhaha@gmail.com.

이 문서는 현재 구현에 맞춘 공개 게시 준비본입니다. 실제 서비스 공개 전에 서버·로그인·삭제 경로와 공개 주소를 검증하고 시행일을 확정합니다.

## 처리하는 정보와 목적

Google·카카오 로그인으로 확인한 제공자 계정 식별자, 서비스 계정·기기 식별자와 기기 이름, 인증 증명을 로그인·계정 연결·기기별 접근 관리에 사용합니다. 이메일 주소로 서로 다른 계정을 자동 합치지 않습니다. 실제 로그인 제공자가 별도로 처리하는 정보는 해당 제공자의 정책에 따릅니다.

사용자가 입력한 곡·녹음 정보, 메모·태그·플레이리스트는 기기에서 관리하고 계정의 정보 동기화에 사용합니다. 마이크 권한을 허용하고 녹음을 시작하면 음성을 기기에 저장합니다. 보관 조건과 사용자 동의에 따라 서비스 서버 사본을 올릴 수 있습니다. 녹음 파일을 올리지 않는 것과 정보 동기화는 별개입니다. 녹음 파일을 로그인 제공자나 곡 검색 제공자에게 보내는 기능은 없습니다.

작업 식별자·종류·결과·시각·성능·저장량·보관 요청 유형은 장애 대응과 서비스 수요 집계에 사용합니다. 운영 분석 기록에 원음·메모·인증 토큰·서명 주소 전체를 넣지 않습니다. 현재 서버 집계만으로 오프라인 이용이나 실제 재생 횟수를 모두 확인하지 않습니다.

## 외부 서비스와 보호

Google·카카오 인증, Manana 곡 검색·차트, 서버/MySQL과 Cloudflare R2 보관 기능을 이용합니다. 각 기능에 필요한 범위로 처리하며 광고·데이터 판매·유료 결제 기능은 현재 구현하지 않았습니다. 실제 제공자 처리와 이전 지역 등은 공개 서비스 연결을 확정할 때 이 문서와 스토어 표시에서 함께 확인합니다.

서비스 통신은 HTTPS를 사용하고 운영 백업은 인증 암호화로 보호합니다. 이는 사용자의 기기·운영 계정 침해까지 막거나 모든 관리자 접근을 금지하는 종단 간 암호화 보장이 아닙니다. 내보낸 ZIP에는 개인 콘텐츠와 녹음이 포함될 수 있으며 일반 사용자 ZIP은 운영 백업 암호화와 다릅니다. 사용자가 외부에 저장·공유한 사본은 직접 관리해야 합니다.

## 보관·삭제와 사용자 선택

계정 정보와 사용자가 유지하는 콘텐츠는 서비스 제공을 위해 보관합니다. 서버 사본 보관 상태와 기기 파일 상태는 구분하며, 서버 사본 정리를 녹음 정보의 영구 삭제로 표시하지 않습니다. 앱에서 휴지통·영구 삭제·계정 탈퇴·백업 내보내기를 선택할 수 있습니다.

계정 삭제는 앱 설정의 ‘계정 탈퇴’와 별도 웹 삭제 경로에서 계정 소유 확인 후 요청합니다. 접수하면 새 세션·새 파일 주소·업로드를 차단하고 진행 중 작업과 기발급 주소를 처리한 뒤 서버 파일·계정 데이터·백업 부재를 확인합니다. 운영 백업에 최대7일 남을 수 있으며 장애로 기한을 넘으면 경고·재시도하고 완료로 숨기지 않습니다. 최소 삭제 확인증·탈퇴 제어 정보는 접수 후30일과 백업 부재 확인 조건을 충족한 뒤 정리합니다. 살아 있는 계정의 영구 삭제 식별자는 삭제 항목 재생성 방지에 필요한 최소 범위로 유지합니다.

오프라인 기기의 삭제 상태는 재연결 때 반영됩니다. 앱 밖 ZIP·M4A 사본을 서버가 원격 회수하지는 못합니다. 기존 파일 주소는 만료 또는 실제 객체 삭제 전까지 남을 수 있습니다. 처리 장애와 기한 초과는 삭제 상태 화면에서 확인하며 위 문의 주소로 문의할 수 있습니다.

## 공개 전 확인

실제 공개 HTTPS 개인정보 주소·웹 계정 삭제 주소, 로그인 제공자 설정, 서버 삭제 작업 활성화와 동작, 스토어 데이터 보안 항목을 검증해야 합니다. 현재 노트북의 localhost 주소는 외부 이용자가 접근할 공개 주소가 아닙니다. 시행일·제공자 처리 범위가 확정되면 앱과 웹·스토어의 안내를 함께 갱신합니다.
