# P02-07 녹음 실패·중단 분류 검증

## 적용 범위

- CAPTURING: Android 녹음기가 실제 파일을 기록 중인 상태
- INPUT_PENDING: M4A 검사와 최종 파일 이동이 끝났고 곡 정보 입력을 기다리는 상태
- SAVED: 이후 기록 저장 단계에서 사용할 로컬 저장 완료 상태
- INTERRUPTED: 마이크 입력 차단, 저장 공간 부족, 쓰기 실패, 프로세스 종료로 녹음을 완료하지 못한 상태
- CORRUPT: M4A 오디오 트랙 검사 또는 녹음 종료 마무리에 실패해 재생 불가로 판단한 상태

## 분류 원칙

- 통화/음성 통신 중 시작 시도는 phone_or_communication으로 분류한다.
- 그 밖의 마이크 시작 실패는 other_app으로 분류한다.
- 최소 여유 공간 미달은 storage_low로 분류한다.
- 디렉터리·파일 생성 또는 최종 이동 실패는 write_failed로 분류한다.
- 비정상 종료 후 파일이 없으면 INTERRUPTED, 파일이 있으나 오디오 검증이 실패하면 CORRUPT로 분류한다.
- 오디오의 음량은 검사하지 않는다. 따라서 무음 녹음만으로 실패 처리하지 않는다.

## 자동 검증

- 네이티브 상태 맵의 localState 및 interruptionReason 변환
- 녹음 중단, 재생 불가, 곡 정보 입력 대기 안내 표시
- 기존 녹음 시작·종료·6분 제한·복구 회귀 테스트
