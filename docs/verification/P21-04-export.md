# P21-04 개인 data.json

## 요구사항·구현
- 원본 계획서 v1.0 P21-04(p945–947), 설계서 10.1(p570–571/582), R103 및 D10. 개인 곡·버전·목록·녹음·분류·revision·미전송 변경·삭제 상태를 직렬화한다.
- account_store.dart의 기존 계정 읽기 트랜잭션에 적용 완료 스냅샷의 19개 개인 엔터티 행과 녹음 저널의 복구 입력 읽기를 추가했다. 현재 계정으로 제한하며 큐 ACK·커서 적용·파일 쓰기·삭제를 수행하지 않는다.
- export_fields.dart는 실제 SnapshotSourceRows의 개인 열과 기존 로컬 비즈니스 투영 필드만 허용한다. export_data.dart는 고정 서버 행, 로컬 서버/초안 사본, 미전송 큐(op_id/base_revision/기준값/변경/서버 충돌값), 완료 녹음의 미저장 입력 폼을 별도 영역으로 보존한다.
- 최신 온라인 서버 행은 로컬의 오래된 확정 서버 사본보다 우선한다. 로컬 초안은 별도 보존하고 읽기/수집용 records 뷰에 반영한다. 복합 키 태그·고정 슬롯·삭제 항목·변경 이력은 UUID만으로 병합해 버리지 않는다.
- 삭제 표식·lifecycle_state·삭제 시각·파일 삭제 시각·목록 부모 revision을 유지한다. 휴지통 선택은 음성 파일 수집 선택이며 삭제 관련 메타정보를 버리는 기준이 아니다.
- 필드별 허용 목록을 중첩 JSON에도 적용한다. 공용 차트/검색 캐시·인증/갱신/상태 토큰·객체 키·서명 URL·기기 경로·복구 저널의 경로는 data.json에 넣지 않는다. 사용자 제목·메모 내용은 유지한다.
- 일시적인 검색 선택 source_token은 제외하고 requires_source_refresh로 새 증명 필요를 기록한다. 백업을 가져올 때 역사적 quota/고정 상태/출처가 현재 인증·권한·동기화 커서를 부여하지 않는다(P22에서 현재 상태 대조).
