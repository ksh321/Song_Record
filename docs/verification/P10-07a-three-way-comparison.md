# P10-07a — 기준값·로컬 입력·서버값의 3방향 비교

2026-10-01. 원본 설계서 검색 p00300~305, 구현계획서 p00593~595(P10-07 충돌 처리). 네트워크·큐 변경 없이 필드별 비교만 담당하는 독립 기반이다. 전체 P10-06/P10-07 완료를 의미하지 않는다.

## 구현과 현재 모델 검토

- 기준값과 서버값이 같고 로컬만 바뀐 필드는 안전한 재적용 후보로 반환한다. 서로 같은 최종값과 로컬 무변경은 요청이 필요 없는 것으로 분류한다.
- 같은 필드에 서로 다른 수정이 있으면 어느 한쪽도 선택하지 않고 충돌 필드 집합을 반환한다. 결합된 필드는 atomicGroups로 함께 비교해 개별 변경을 합쳐 잘못된 조합을 만들지 않는다.
- 필드 부재는 null과 다르다. 기준 정보가 없으면 명시적인 서버 동일값 외에는 자동 병합 후보로 만들지 않는다. 장치 시각을 승자 판단에 사용하지 않는다.
- 엔티티 ID·revision·양쪽에 명시된 소유자 차이를 검사한다. 이 순수 비교는 계정 인증이나 도메인 입력 검증을 대신하지 않는다.
- 입력과 결과를 분리하고 충돌 목록을 불변으로 보관한다. 기존 큐·wire·op_id·원본 스냅샷을 수정하지 않는다. safePatch는 후보이며 충돌이 있는 전체 요청을 자동 전송해도 된다는 뜻이 아니다.
