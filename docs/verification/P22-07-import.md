# P22-07 revision 충돌 미리보기

- 계획 원문 p00986~988·설계10.2~10.3·R112와 기존 3방향 비교 계약을 대조했다. 사용자 지정 6.1 Sol/medium 원수 직접 구현 및 현재 모델 별도 검토.
- import_conflicts.dart는 계정별 최신 서버 값·백업 기준 revision·백업의 명시 로컬 변경·대상 기기의 미전송 변경을 비교한다. 과거 서버 사본 자체를 수정 요청으로 취급하지 않는다. 같은 필드 충돌·기준 revision 불일치·미지원 작업·녹음 곡 연결 차이는 보류한다. 키 쌍과 녹음 시각 필드는 기존 atomic group 비교를 재사용한다.
- 계정 guard를 비동기 전후 확인하고 로컬 상태의 fence를 제공한다. 반환은 읽기 전용 미리보기이며 DB 적용·큐 재전송/ACK·파일 교체를 수행하지 않는다. 후속 P22-09 적용은 최신 상태를 재검증하고 명시 필드 변경만 사용해야 하며 미리보기 전체 payload로 대상 로컬 초안을 대체해서는 안 된다.
- account_store.dart의 파일 검사는 실제 앱 전용 기존 파일의 체크섬을 읽는다. DB 행이 없거나 파일을 재생 가능으로 증명할 수 없다는 이유로 기존 바이트를 없는 파일로 취급하지 않는다. 다른 체크섬·백업 설명/서버 명세 불일치는 파일을 보류하고 동일 체크섬만 재사용 후보로 표시한다.
- import_conflict_preview.dart는 기준·서버·백업·대상 로컬 값과 보류 상태를 가상 목록으로 표시한다. 기본 승자나 복원 성공을 표시하지 않는다. 전체 가져오기 화면의 명시 선택·적용 결합은 후속 P22-09~11에서 수행한다.
- 영향 검사 10개 PASS·분석 지적0. 가상 시간 안에서 DB 준비가 대기한 위젯 테스트는 준비를 runAsync로 분리했고, 실행에 통과하던 dynamic 인수는 분석 기준에 맞게 String 타입을 명시했다. 제품 오류와 시험 준비 오류를 구분했다.
- 현재 모델 별도 코드 검토: 최신 revision 유지·같은 필드/연결 충돌 보류·계정 격리·미전송 초안/기존 파일 무변경·소스와 테스트 기대값 대조 PASS. 읽기 전용 내부 비교와 위젯 범위로 이 번호의 추가 폰 실기 없음. 전체 회귀와 최종 SHA의 필수 CI는 실제 결과 확인 후 기록한다.
- 학습: 오래된 백업의 값과 사용자의 변경은 다르다. 기준 값에서 바뀐 필드만 비교하고 충돌은 선택 전까지 보존해야 한다.
