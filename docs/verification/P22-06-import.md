# P22-06 구형 KY 후보 보류

- 계획 원문 p00983~985·설계10.2(p00591)·R111과 현재 TJ 목록 후보 계약, HTML import-preview/공통 UI·시각 토큰을 대조했다. 6.1 Sol/medium 원수 직접 구현·현재 모델 별도 검토.
- planImportCandidates는 기존 UUID 계획 중 곡 미연결 목록 후보를 검사한다. KY 브랜드/스냅샷/출처 후보만 LEGACY_KY_CANDIDATE로 보류하고 등록곡은 후보로 재해석하지 않는다. 확인 불가 브랜드·스냅샷은 INVALID_CANDIDATE로 별도 보류한다. 원본 항목/번호/스냅샷은 보류 근거에 보존하며 TJ로 바꾸지 않는다.
- 정상 TJ·등록곡·녹음 정보와 검증된 파일 ID 집합은 유지한다. 같은 숫자의 KY/TJ도 자동 병합하지 않는다. 문자열/배열은 불변 또는 복사이며 원본 UUID 계획은 변경하지 않는다.
- ImportCandidateHolds는 보류 사유와 TJ에서 찾아 다시 선택 버튼을 제공한다. 제목 검색 힌트는 Unicode scalar200개 이내다. 버튼은 후속 기존 TJ 검색의 명시 탐색 요청만 전달하고 오래된 번호/선택 증명을 재사용하거나 데이터에 적용하지 않는다.
- 영향8개 PASS·Flutter 전체1125개 PASS·분석지적0. KY만 보류/파일 전체 보존, TJ 행의 KY 스냅샷, 등록곡, 미지원/누락 후보, Unicode/원본 복사, 계정 guard, 사유·명시 검색 버튼의 무변환을 확인했다. 위젯 검증 범위이며 이 번호에서 추가 폰 실기 없음.
- 현재 모델 별도 검토 PASS: KY 자동 변환/파일 폐기 없음, 후보와 등록곡 구분, 정보/원본 보존, 탐색 요청과 실제 등록/적용 분리 및 후속 fresh source proof 조건을 대조했다. 소스 해시와 실행 로그는 Git 제외 .local/workflow/p22-06/에 보존한다.
- 실제 검색 화면·source proof·적용 결과 결합은 후속 P22 및 전체 진입 P22-11에서 이어간다. 최종 필수 Flutter CI를 확인한다.
- 학습: 브랜드가 다른 같은 번호는 같은 곡을 보장하지 않는다. 보류 사유를 유지한 채 해당 브랜드의 새 검증 결과를 사용자가 선택해야 한다.
