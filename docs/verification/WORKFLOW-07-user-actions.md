# WORKFLOW-07 — 사용자 확인 목록

2026-09-29 사용자 요청에 따라 루트 `내가할일.md`를 단일 확인 목록으로 추가했다. 기존 USER-001 로그인 빌드 설정은 확인 필요 1건, USER-002 USB는 사용자 연결 응답 뒤 AI의 device 확인으로 완료했다. 기존 PC 스크립트 실행을 폰 실기로 처리하지 않았다. 새 실기는 APK 준비 전 요청하지 않는다.

- AGENTS.md / development-workflow.md: 파일 선기록, 요청 필수 정보/상태, 완료 기록 이동, 코드/판본 변경 안내, 진행·종료 보고의 건수·링크 규칙 통합.
- phone-notify.ps1: 시험 이외 알림은 기록된 ItemId 필수. 단일 문서 항목·확인 필요 상태·작업/판본 일치·판본 변경 이유를 확인한다. ID/판본별 로컬 전송 기록으로 성공/불확실 전송 모두 중복 차단한다. 고정 행동 문구만 보내고 서버 접수를 실제 수신으로 표시하지 않는다.
- 기존 USER-001 알림 접수 기록을 로컬 판본 기록에 연결했다. 새 알림은 보내지 않았다. 공개 문서에 topic·키·기기 ID를 기록하지 않았다.
- `tools/tests/workflow-gates.ps1`: 실제 HTTP 대신 격리 모의 호출, 69 검증 통과. 문서/ID 없는 요청, 기록되지 않은 판본, 변경 이유 누락, 완료 항목, 성공/불확실 중복 전송 차단 포함. 최초 Action 변수 충돌은 수정 후 재검증했다.
- 별도 Sol/medium 검수의 2지적(ID 선택적·판본 사전 기록 미확인)을 보완했다. 추가 Sol/high 검수의 행동 불일치 지적도 문서의 알림 종류/행동 일치 검사로 보완했다. 기존 요청 원장 연결 근거를 제공한 최종 별도 Sol/high 검수에서 추가 차단 없음. Standard/default·Fast 끔 요청, 실제 tier 미확인.

대상 커밋·필수 CI는 커밋 후 확인하며 아직 성공으로 추정하지 않는다. 사용자 답변 때 문서와 상태를 갱신하는 것은 활성 작업의 운영 규칙이며 세션 종료 후 상시 자동 실행을 보장하지 않는다.
