- 원본 계획 p00977~979·설계10.3/R109 대조. 화면 HTML backup-import/import-preview, UI_REFERENCE 공통 조작·SafeArea와 색상 JSON의 원본 정규화 해시를 확인했다. 6.1 Sol/medium 원수 직접 구현·현재 모델 별도 검토.
- ImportDecision는 검증 완료 전 승인을 만들지 않는다. 손상이면 전체 가져오기를 차단하고 파일별 오류를 표시한다. 구조·필수 JSON·상태 오류는 부분 선택도 허용하지 않는다. 정상 정보/파일의 별도 명시 선택만 부분 미리보기 권한을 만들며 손상 항목을 자동 건너뛰어 성공 처리하지 않는다.
- 포함된 파일과 알려진 파일 오류에만 부분 선택을 허용한다. 정상/제외 파일 ID는 불변 집합이며 취소·계정 변경·재검사·dispose는 승인 사용을 차단한다. 검사에 전달한 세대 guard는 늦은 결과/취소 후 결과를 폐기한다. 데이터 적용 API는 없다.
- ImportDecisionScreen은 정보/정상/미포함/제외 개수를 구분하고 아직 복원되지 않았음을 표시한다. SafeArea+스크롤, 첫10개 파일별 오류와 가상화한 전체 목록을 제공한다. 정상 파일 계산은 오류 집합을 한 번 만들어 선형으로 수행한다.
