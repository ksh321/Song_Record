# P22-08 대표와 고정 대조

- 원본 계획 p00989~991·설계10.2(p00593)·R112/R114와 기존 대표 저장의 same-owner/same-song/SAVED/ACTIVE 조건, PIN_SLOT·UserEntitlement 계약을 대조했다. 사용자 지정 6.1 Sol/medium 원수 직접 구현·현재 모델 별도 검토.
- import_roles.dart는 현재 서버 곡의 대표 선택(명시 해제 null 포함)을 유지한다. 신규 곡만 동일 소유자·같은 곡·저장 완료·활성 녹음을 대표로 허용하며 확인 불가·휴지통·삭제 상태 후보는 보류하고 연결을 비운다. 녹음 정보와 파일은 폐기하지 않는다.
- PIN_SLOT·SONG_CLOUD_SELECTION·권한/용량/삭제·asset 등 서버 소유 상태를 과거 ZIP 적용 대상으로 반환하지 않는다. 기존 current/pending 고정은 한 슬롯으로 집계하고 비어 있는 슬롯은 사용 중으로 계산하지 않는다.
- 과거 고정은 현재 유효한 녹음 중 현재 선택되지 않은 항목만 후보로 제공한다. 현재 entitlement와 무료 상한10개를 함께 적용하며 권한 정보가 없으면 여유0으로 보수 처리한다. 명시 선택 결과는 제안이며 과거 slot/revision을 재생하지 않는다. 실제 재신청은 후속 적용에서 최신 서버 revision과 기존 고정 API를 사용한다.
- import_role_selection.dart는 SafeArea·가상 목록을 사용한다. 기본 선택은 없음, 여유 초과 체크 제한, 선택 확인 및 계정 guard를 제공하고 아직 신청하지 않았음을 표시한다. 새 계획으로 바뀌면 이전 선택을 비운다.
- 영향9개 PASS·분석 지적0. 서버 대표 유지/해제, 신규 대표 조건, 과거 고정 무자동 복원, current/pending/빈 슬롯, 현재 한도/권한 미확인, 서버 소유 상태 배제, 외부 계정/guard, 무변경/복사, 미선택 및 사용자 명시 선택을 확인했다.
- 현재 모델 별도 검토 PASS: 오래된 ZIP의 대표 변경·고정 해제 취소 없음, 현재 한도 우회 없음, 기본 선택 없음, 상태/파일 무변경, 적용 제안과 실제 API 요청 분리. 이 번호는 내부 정책/위젯 검증이며 전체 가져오기 설치본은 P22-11에서 결합 검증한다.
- 학습: 백업에 선택 기록이 있어도 현재 서버 선택을 되돌릴 권한은 아니다. 최신 상태와 현재 한도를 읽고 필요한 항목만 새 요청으로 신청한다.
