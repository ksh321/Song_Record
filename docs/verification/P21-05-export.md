# P21-05 읽기용 recordings.csv

## 요구사항·구현
- 원본 계획서 v1.0 P21-05(p948–950), 설계서 10.1(p572–573/582), R104/D10.
- recordings_csv.dart는 같은 export_id/source_user_id/정보 수의 고정 data.json과 수집 완료 manifest를 사용한다. 미수집 상태·다른 기준은 최종 CSV로 쓰지 않는다.
- 한국어 머리글: 녹음 ID·곡명·가수·버전·키·녹음 시각·시간대·티어·메모·파일 포함·미포함 사유·정보 상태·삭제 상태. 기존 버전/키 표시 함수를 재사용하며 미연결·입력 대기도 읽기용 행으로 기록한다.
- 확정 녹음 스냅샷을 우선하고 없는 곡명/가수는 연결 곡에서 찾는다. DRAFT 미저장 입력 폼은 읽기용에 표시하되 ‘입력 대기 · 미저장 입력 포함’으로 구분한다. data.json 원값은 변경하지 않는다.
- 포함 여부는 최종 manifest에서 확인한다. 클라우드 상태만으로 파일 포함을 추정하지 않는다. 누락 사유와 삭제 상태를 별도 열로 제공한다.
- UTF-8 BOM·CRLF·모든 셀 따옴표와 이중 따옴표 이스케이프. 수식 시작 =/+/-/@ 앞 공백·제어문자·BOM 우회와 탭/CR/LF 시작도 작은따옴표로 중화한다. 사용자 원문은 보호 접두사 뒤에 유지하고 data.json은 그대로 보존한다.
