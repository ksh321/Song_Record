- 문제 분리: 첫 가져오기에서 일반 CREATE TRIGGER에 남은 이전 관리자 definer로 MySQL1227. 관리자 권한을 주지 않고 DDL만 현재 복원 계정 기준으로 바꾸는1회 보완 후 가져오기 PASS. 별개 원인으로 export_session_state 집계 뷰가 소유자 테이블로 오분류되어 차단. BASE TABLE만 조회하도록1회 보완 후 실제 전체 복원 PASS. 다른 원인을 합산하지 않음. 실패 환경을 보존하고 원래 DB를 초기화하지 않음.
- 검토: 현재 모델이 실제 diff·완료 조건·새 DB/계정 경계·메모 보존·원장 최신성·파일 목록·원래 데이터 불변·정확한 시간 범위를 대조. 별도 에이전트/추가 모델 호출 없음. 전체 공개 서비스 RTO·실제 OAuth/사용자 세션 복구는 미검증이며 P25 출시 검증과 구분한다.
