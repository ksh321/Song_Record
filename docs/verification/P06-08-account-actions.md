# P06-08 — 로그인 수단 해제 / 기기 로그아웃

기준 커밋: `e5c8865b8e9f131b81726688e2eeb4897d9e93e3`.

## 동작

- 설정의 로그인 계정 연결 화면에서 연결된 수단을 해제한다. 마지막 수단은 UI와 서버 모두 차단한다.
- 동일 사용자 행 잠금으로 동시 해제/연결을 직렬화한다. 해제 시 진행 중 연결 challenge를 취소한다.
- 해제는 계정/기록/현재 세션을 삭제하지 않는다. 남은 수단으로 동일 사용자 계정에 로그인한다.
- `POST /v1/auth/logout`은 refresh proof와 device ID로 해당 세션만 폐기한다. access 만료 후에도 가능하며 재호출에 안전하다. 다른 기기 세션은 유지한다.
- 앱은 서버 응답과 로컬 로그아웃 표식 저장 후 계정 저장소를 닫는다. 서버 연결 실패 시 완료로 표시하지 않는다.
- 로그아웃은 DB/파일을 삭제하지 않는다. 진행 중 토큰 갱신이 끝난 뒤 로그아웃한다.
- Android 녹음 파일·복구 journal·재생을 환경/사용자별로 분리한다. 녹음 중 로그아웃/백업은 차단한다.

## 로컬 복구 파일의 범위

로그아웃 화면에서 Android 파일 저장 창으로 ZIP을 저장할 수 있다. 현재 계정의 로컬 DB 테이블을 일관된 JSON snapshot으로 내보내고, 계정별 녹음 파일과 journal을 함께 저장한다. 파일별 SHA-256과 크기를 기록한다. 로그인 토큰은 포함하지 않는다.

이 ZIP은 P21/P22의 완성된 이식용 백업 형식이 아니다. 앱으로 ZIP을 가져오는 기능, 서버에만 있는 자료, import 원본 아카이브는 포함하지 않는다. 미완료 오디오의 재생은 보장하지 않는다. 저장 취소/실패 시 원본을 유지한다.

기존 prototype 전역 녹음은 소유 계정 정보가 없어 임의로 현재 계정에 연결하지 않는다. 기존 파일을 삭제하지 않지만 새 계정별 화면/ZIP에서 노출하지 않는다. 실제 계정 분리 시험에는 이번 패치 이후 만든 새 녹음을 사용한다.

## 자동 검증

- 서버: 마지막 수단, 타 계정 해제, 동시 해제, 남은 수단 로그인, challenge 취소, 다른 기기 보존, 만료/중복/회전된 refresh proof 로그아웃 및 HTTP routing 테스트.
- Flutter: 로그아웃/재로그인, offline 보존, refresh 경쟁, 로그아웃 표식 복원, 녹음 중 차단, 계정별 로컬 snapshot 테스트 추가.
- 실제 실행 결과와 실행 환경 제한은 배포 ZIP의 README.md에 기록한다.
- Android APK 및 실기기 검증은 적용 스크립트와 아래 체크리스트로 수행한다. DB migration은 추가하지 않는다.

## 실기기 체크리스트 (미실행)

1. 두 로그인 수단이 연결된 계정 A에서 새 시험 녹음을 만들고 재생한다.
2. 한 수단을 해제한다. 남은 수단의 해제 버튼은 비활성이고 앱의 계정/기록은 유지되어야 한다.
3. 설정 → 로그아웃에서 로컬 복구 파일 저장을 취소한다. 로그인 상태가 유지되어야 한다. 다시 저장하고 ZIP을 확인한다.
4. 로그아웃한다. 로그인 화면으로 이동해야 한다. 앱을 완전히 종료하고 재시작해도 로그인 화면이어야 한다.
5. **남겨 둔 로그인 수단**으로 A에 로그인한다. 같은 계정의 새 시험 녹음이 재생되어야 한다.
6. 로그아웃 후 별개의 기존 계정 B로 로그인한다. A의 새 시험 녹음이 보이거나 재생되면 실패다. 다시 A로 돌아가면 유지되어야 한다.
7. 서버를 잠시 중지한 상태에서 로그아웃을 시도한다. 실패 안내가 표시되고 성공으로 처리하지 않아야 한다. 서버 재개 후 재시도한다.
8. 녹음 중 로그아웃/복구 파일 저장이 차단되는지 확인한다. 녹음은 정상 종료 후 재시도한다.
9. 두 번째 기기를 쓸 수 있으면 한 기기 로그아웃 후 다른 기기의 세션이 유지되는지 확인한다.

해제한 수단으로 곧바로 로그인하면 별개의 신규 계정이 생성될 수 있다. 같은 기록 확인에는 반드시 남은 수단을 사용한다. 다시 연결하려면 로그인 상태에서 연결 흐름을 사용한다.
