# P02 08 Android 녹음 실기 검증 기록

## 목적

P02 녹음 시제품의 권한, 잠금 녹음, 입력 충돌, 파일 복구 동작을 제조사와 Android 버전별로 기록한다. 실행하지 않은 항목은 통과로 표시하지 않는다.

## 구현 선택

현재 시제품은 Flutter 녹음 플러그인 대신 Android MediaRecorder와 포그라운드 서비스를 직접 연결한다. Samsung SM-A546S에서 백그라운드 녹음, 잠금 화면 카드 알림, 알림 종료, 파일 재생, 알림 선택 후 앱 복귀가 확인되었으므로 P03 이후에도 네이티브 구현을 유지한다. 다른 제조사에서 차단 결함이 발견되면 그때 호환 계층 또는 플러그인 도입을 다시 검토한다.

## 기기 정보 수집

녹음 시제품 화면은 다음 값을 Android에서 직접 읽어 표시한다.

- 제조사
- 모델명
- Android 버전
- SDK 버전

검증 결과에는 화면에 표시된 값을 그대로 기록한다.

## V01부터 V04 판정

| ID | 통과 기준 | 현재 판정 |
|---|---|---|
| V01 | 권한 거절 시 녹음하지 않고 이유와 재시도를 제공하며 재허용 후 정상 녹음 | 미실행 |
| V02 | 잠금 상태에서 5분 30초와 5분 50초 무음 안내 후 6분에 종료되고 파일 재생 가능 | 미실행 |
| V03 | 통화와 다른 앱의 입력 차단 사유를 구분하며 단순 무음 녹음은 유지 | 미실행 |
| V04 | 종료 직후 또는 저장 중 강제 종료해도 같은 UUID로 복구되고 파일 손실과 중복 없음 | 미실행 |

## 실기 실행 순서

1. 화면의 검증 기기 정보를 기록한다.
2. V01 권한 거절과 재허용을 확인한다.
3. V02 화면을 잠근 채 6분 녹음을 끝까지 실행한다.
4. V03 실제 통화 중 시도, 다른 녹음 앱 실행 중 시도, 조용한 환경의 무음 녹음을 각각 확인한다.
5. V04 녹음 종료 직후 앱 프로세스를 종료하고 다시 열어 같은 녹음 ID와 파일이 한 개만 남는지 확인한다.
6. 각 결과를 통과, 실패, 미실행 중 하나로 갱신한다.

## 완료 조건

V01부터 V04까지 실제 기기 결과가 모두 기록되고 실패 항목이 없을 때 P02 08을 완료로 변경한다. 자동 테스트와 빌드 성공만으로 실기 결과를 대신하지 않는다.
