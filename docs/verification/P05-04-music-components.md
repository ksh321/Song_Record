## 구현

- 등록곡은 기본 버전도 생략하지 않고 키·티어를 표시한다. 목록에서 TJ 번호를 숨기고
  요약에서 번호를 보여준다. 수동곡은 TJ 번호 없음, 키·티어 미선택은 미정이다.
- 후보 데이터에는 개인 키·티어·버전 필드가 없다. 검색/차트에는 출처와 문자열 번호를,
  차트에는 순위를 표시한다. 플레이리스트 후보에는 제목·가수·미등록 표시만 보인다.
  금영 후보를 플레이리스트 행으로 만들 수 없다. 번호 앞자리 0과 제목의 괄호 문구를 보존한다.
- 이미 목록에 추가된 등록곡은 추가됨을 표시하고 터치·키보드 활성 콜백을 연결하지 않는다.
- 녹음 행은 현재 연결곡 대신 RecordingSnapshot을 사용한다. 저장 시각과 오프셋으로 날짜를
  표시하며 길이·티어·버전·키·가수·파일 상태를 포함한다. 미연결 녹음은 곡 미연결 표시를 쓴다.
  파일이 없어도 녹음 정보 상세 콜백은 사용할 수 있다. 재생 가능 여부를 이 행이 추정하지 않는다.
- SongSummary의 메타데이터는 읽기 전용이며 곡 수정 버튼만 편집 콜백을 호출한다.
  아쉬운 점과 빈 메모 안내를 표시한다. 장식 음악 아이콘을 넣지 않는다.
- 역할 카드는 기존 RecordingSelection을 입력받는다. 대표·최신·최저 티어 세 행은 항상 보이고
  uniqueIds로 대상 개수를 센다. 표시 데이터 누락이나 다른 곡의 녹음은 거절한다.
  계정 권한·선정 자격 검사는 도메인 계층에서 수행해야 하며 UI 검사가 이를 대신하지 않는다.
- 역할 선정과 실제 파일 상태는 독립적이다. 대상 1개는 서버 파일 1개를 의미하지 않는다.
  대표 미지정은 자동으로 채우지 않고, 지정/변경과 최신/최저 상세 진입을 콜백으로 분리한다.
- 역할 설명만 접을 수 있다. 최소 행 높이 66/86/62와 기존 텍스트·색·간격 토큰을 재사용한다.
  큰 글꼴과 좁은 행에서는 등록곡 메타데이터를 다음 줄로 옮기고 제목을 말줄임하지 않는다.

## 구현 경계

기본 앱에 샘플이나 가짜 DB를 연결하지 않았다. 실제 곡 조회·등록·수정·플레이리스트 추가·
재생·업로드·대표 선택의 처리 로직은 후속 기능의 책임이다. 네이티브 녹음, SQL, Drift,
의존성, 내비게이션 및 앱 실행 환경은 변경하지 않았다. 미리보기 버튼은 샘플 안내만 표시한다.

키 표시에는 기존 MusicalKey와 형식 함수를 재사용한다. UI_REFERENCE의 원키 비영 반음 예시와
현재 도메인의 원키=0 제약 차이는 이번 표시 단계에서 임의로 바꾸지 않는다.
P05-06 키 선택기 구현 시 설계 기준과 함께 정리해야 한다.
전체 접근성 및 실제 목록 화면 검수는 P05-08 및 후속 기능 연결에서 이어간다.
