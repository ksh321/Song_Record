# P21-02 진행 중 녹음 처리

- 원수 6.1 Sol/medium. 계획 원본 [p00939–p00941], 설계 10.1 [p00565], D10 일관성 1·4항을 대조했다. 선행 P21-01 완료 SHA aa78dbe8a946ac71ca149fa6676510de69ad05f3, 필수 CI 38130018334·38130018321·38130018322 PASS.
- `ExportPreparation`은 백업 기준 취득 전 준비 경계다. 진행 중 녹음을 기존 stop 명령으로 종료하고 같은 recording_id의 completed 상태를 제한 시간 내 확인한다. 종료 실패·타임아웃·취소·계정 전환·불완전 상태에서는 백업을 시작하지 않는다.
- 기존 녹음 화면의 완료 파일 저장을 `preserveCompletedCapture`로 공유했다. 실제 완료 읽기의 계정 범위·ID·MIME·AAC profile과 기존 저장소의 파일 길이·해시 검증을 유지한다. 파일과 DRAFT를 먼저 보존하고 서버 전송을 새로 강제하지 않는다.
- 저장소에 이미 등록된 recording_id는 재등록하지 않는다. 삭제 표식도 기존 자료로 확인하므로 오래된 네이티브 완료 표시가 삭제를 되돌리지 않는다.
- `RecorderGateway`의 네이티브 이벤트를 하나의 broadcast stream으로 공유한다. 백업의 임시 구독 취소가 기존 녹음 화면의 이벤트 수신을 끊지 않도록 실제 이벤트 채널 회귀로 확인한다.
- 임시 공간은 음성 작업 사본+ZIP, 메타 자료 사본, ZIP/압축 여유·파일별 헤더·16MiB 안전 여유를 포함해 보수적으로 계산한다. Android는 앱 내부 cacheDir의 실제 StatFs availableBytes를 반환한다. 공간 조회는 예약/완료 보장이 아니며 수집 전 실제 대상량으로 재계산하고 출력 중 부족은 후속 P21-07/09에서 실패로 처리한다. 외부 저장 위치의 여유 공간과도 구분한다.
- 음성 재생·녹음기의 기본 native stop/검증 동작은 변경하지 않았다. 새 UI 조작은 없으므로 이 번호는 기존 실제 녹음 완료 근거와 회귀·Android 빌드로 검증한다. 백업 화면의 실제 안전 종료·파일 저장·중단은 P21-08/09에서 설치본으로 확인한다.
- 대상 9개 PASS: idle, 안전 종료 후 보존, 종료 실패 원본 유지, 미완료 타임아웃, 손상/중단 거절, 취소/계정 전환, 공간 계산 경계, 부족 거절, 구독 취소 후 화면 이벤트 유지.
