# P02 04 05 녹음 시간 제한과 종료 경로 검증

## 구현 범위

- Android 단조 증가 시계로 녹음 경과 시간을 계산한다.
- 5분 30초부터 30초 종료 임박 상태를 화면과 무음 진행 알림에 표시한다.
- 5분 50초부터 10초 종료 임박 상태를 화면과 무음 진행 알림에 표시한다.
- 6분에 녹음 서비스가 자동으로 파일 마무리 절차를 시작한다.
- 앱 버튼, 알림 버튼, 6분 제한, 서비스 종료 요청이 같은 중복 안전 종료 함수로 합류한다.
- 완료 상태에 종료 원인을 남기며 6분 제한 종료는 화면에 별도로 안내한다.

## 자동 검증

- Flutter 상태 변환 테스트로 30초 및 10초 경고와 남은 시간을 확인한다.
- Flutter 위젯 테스트로 5분 30초 및 5분 50초 안내 문구를 확인한다.
- Flutter 위젯 테스트로 6분 제한 완료 상태와 06:00 표시를 확인한다.
- Android 개발용 APK 빌드로 네이티브 녹음 서비스의 Kotlin 컴파일을 확인한다.

## 실기기 검증

1. 개발용 앱에서 녹음을 시작한다.
2. 화면을 잠그고 녹음 알림에 소리와 진동이 없는지 확인한다.
3. 5분 30초에 알림이 종료 임박과 남은 시간을 표시하는지 확인한다.
4. 5분 50초에 알림의 남은 시간이 10초로 바뀌는지 확인한다.
5. 6분에 별도 조작 없이 녹음이 종료되는지 확인한다.
6. 앱을 다시 열어 파일 생성 완료, 06:00 부근의 경과 시간, 자동 종료 안내를 확인한다.
7. 완성된 M4A 파일을 재생해 정상 파일인지 확인한다.
8. 별도 녹음에서 앱 종료 버튼과 알림 종료 버튼을 연속으로 눌러도 결과 파일과 녹음 ID가 하나인지 확인한다.

## 통과 기준

- 잠금 중에도 5분 30초 및 5분 50초 무음 안내와 6분 자동 종료가 동작한다.
- 안내음과 진동이 녹음 파일에 들어가지 않는다.
- 어느 종료 경로를 사용해도 완료 파일과 녹음 ID가 중복 생성되지 않는다.
- 자동 종료 파일을 앱에서 다시 열고 재생할 수 있다.
