## 구현
- AudioValidator: 확보한 바이트 6MiB 이하·신고 크기·SHA-256 일치, M4A/MOV 계열 컨테이너·AAC-LC·48kHz·모노·0초 초과 361초 이하 확인 후 FFmpeg 전체 디코딩. 실제 바이트의 읽기 전용 결과만 다음 소비자로 전달한다.
- 스트림/컨테이너 재생 시간을 대조하고 AAC 마지막 프레임 패딩만 1024샘플 이내 허용한다. 361초 상한은 재생 시간 기준으로 엄격하게 적용한다. 비트레이트 정확히 96kbps일 필요 없음.
- 임시 작업 파일은 자기 파일만 정리. 명령 셸 미사용, MOV 입력 강제·외부 data reference 차단, 결과 출력 제한·시간 제한·고정 오류 코드. worker 역할에만 빈 등록.
- P12-06 UploadVerification.Consumer와 then(Next)로 연결. 자동 성공 처리/최종 저장/DB 확정은 하지 않는다. 최종 작성은 P12-09, 추가 자원 제한은 P12-08의 별도 완료 조건이다.
- R2CredentialCheck/DevelopmentAudioProbe/r2_credentials.py: dev.worker 일회용 입력으로 개발 temporary에 새 합성 오디오 생성→다운로드 검증→같은 시험 객체를 손상 바이트로 바꿔 거절 확인→처음 검증한 바이트 보존 확인→시험 객체 정리. 운영 버킷/기존 객체 접근·삭제 없음. 비밀값 stdin 전달, 결과는 허용된 상태만 저장.
- CI 서버 작업에 FFmpeg/ffprobe 준비 추가. 이번 서버 변경과 함께 필요한 CI에서 실제 오디오 검사 실행 예정.
