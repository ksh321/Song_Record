- 현재 계정/기기의 세션·스토어·accountEpoch를 요청 전후 확인한다. 계정 변경 시 이전 값과 늦은 응답을 숨기며 로더 교체 시에도 이전 표시를 지운다. HTTPS 및 로컬 개발 주소만 허용, 리다이렉트 금지, 응답 2MB/15초 한계, 인증 원문/오류 본문 출력 없음.
- 실제 SAF ZIP 선택→엄격 ZIP/음원 검사→사용자 동의→현재 서버 사전 대조→불변 적용 저널→필요한 동기화→실제 결과 집계를 연결했다. 계정 변경/취소는 오래된 작업·표시를 무효화한다. 적용 시작 후 이미 완료한 항목은 보존하고 남은 항목을 중단한다.
- 동일 원본 전체 digest를 가진 기존 저널은 재사용한다. 로컬 미전송 수정도 중복 CREATE 하지 않는다. 실제 큐 계약의 메타데이터·녹음 상태/티어·목록 관계·새 유효 대표를 사용하며 역할/한도/클라우드 상태 등 서버 전용 과거 상태는 되감지 않는다.
- 미등록 후보는 새로운 검증된 선택, 지원되지 않는 보관 분류 명령은 별도 대조가 필요하다. 안전하게 표현할 수 없는 명령은 저널·정상 파일 변경 전에 거절하며 완료로 표시하지 않는다. 실제 서비스 계정과 모든 과거 데이터의 통합 검증은 P25 출시 근거와 구분한다.

## 오류와 보완
- 서로 다른 원인을 합산하지 않았다. 새 테스트의 실제 I/O는 가짜 시간 바깥에서 수행하도록 수정했다. 저장 데이터와 새로 생성되는 조회 시각을 혼동한 기대값은 UTC 형식 검사와 전체 저장 데이터 보존 비교로 분리했다. 기존 태그/미전송 변경을 둔 상태에서 보존을 확인했다.
- 타입/공개 모델 필드 이름/검증 앱의 보호된 알림 호출 지적은 해당 코드로 정정했다. 자동 스타일 수정이 바꾸지 못한 중괄호는 직접 정정했다. 테스트 삭제·데이터 검사 약화·모델/세션으로 실패 횟수 초기화 없음.
- SDK/Gradle 캐시 접근은 승인된 로컬 권한으로 수행했다. 작업 시작 측정·모델/실행 경계·전체 원시 로그는 Git 제외 기록으로 보존했다.
