# P21-03 백업 manifest.json

## 요구사항·변경
- 원본 계획서 v1.0 P21-03(p942–944), R103, D10의 schema_version=1·출처·기준 시각·커서·파일 명세를 구현했다. P21-01의 고정 서버/로컬 기준을 사용한다.
- export_manifest.dart: export_id/source_user_id, UTC 기준 시각, 온라인/오프라인 범위, 확인된 커서, 파일 상대 경로·SHA-256·크기·길이·포함 여부·누락 사유를 생성·검증한다. source_user_id는 과거 출처이며 인증 권한이 아니다.
- 파일 경로는 audio/{recording_id}.m4a로 제한한다. 예상 해시가 있는 누락 파일은 포함으로 세지 않는다. 선택하지 않은 휴지통 파일은 누락과 구분한다. 오프라인 미확인 커서는 NULL이고 전체 온라인 백업으로 표시하지 않는다.
- backup_json.dart: 중복 키(Unicode 이스케이프 포함), 과도한 중첩, 손상 JSON을 거절하고 오류에 입력 원문을 노출하지 않는다. 서버 숫자 정규화와 분리해 schema_version 1.0을 거절한다.
- 고정 파일 목록·카운트·총 바이트를 대조하며 절대 경로·추가 인증 필드·중복 ID를 거절한다. 실제 파일 수집·체크섬 확인·ZIP 완료는 후속 P21-06/07이며 이 명세만으로 파일 검증을 대신하지 않는다.
