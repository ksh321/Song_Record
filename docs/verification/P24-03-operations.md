- 원본 계획 p01041~p01043, 설계 p01093~p01099, R121/R122. 실제 계정 전체 분석 요청·저장 집계에 기반한 예상 월 비용과 5/6/7만원 대응, 임시/백업 포함, 별도 운영비·세금·환율 경계를 기록한다.
- Cloudflare 분석 읽기 키 USER-098 판본2 PASS. 사용자 “자동 조회 확인이라 뜸” 확인. 공식 키 인증·R2 관리 거부·Windows 암호화 보관·독립 자동 조회 PASS. 첫 HTTP401 원인은 미확정. 키/발급 화면을 읽거나 기록하지 않았다.
- tools/cloudflare_metrics.py / r2_cost.py / cost_monitor.py: 분석 전용 읽기·회계 주기8일·무료 분량 계정 단위·단위 올림·ECB 기준일·표본 기반 저장·향후 예상·고정 폰 알림 및 중복 억제. 공개되지 않은 관리 조회 요금 분류는 별도 보수적 예산 추정이며 확정 A/B 실적이 아니다.
- 서버 CostGate/CostOperator/V28: 비용 소유 잠금·최신 관측·재생 방지, 수동/대조 잠금 보존. 신규 예약만 차단하며 기존 진행 중 예약 재조회·나머지 데이터 기능을 보존한다. staging/prod 요청 접수 전 필수 감시 설정. Windows 검증 연결은 시간당 비AI 감시 시작, 종료/절전 중 보장은 하지 않는다.
- [운영 절차](../runbooks/cost-monitoring.md). 현재 운영 백업은 P24-05 미착수, 청구서 실측·카드 결제 FX·세금은 미확인이다. 이를0원/완료 실적으로 대신하지 않는다.

- `services/api/gradlew.bat build --offline` PASS(1분18초). 원수 현재 모델이 별도 검토하여 요청 접수 전 설정·다른 잠금 소유권·관측 재생/만료·기존 예약과 데이터 보존을 대조했다. 추가 영향 UploadReservations/CostGate4개 PASS, 배포/비용 영향 검사와 bootJar PASS.
