# D03 — 한국 시간 날짜 경계와 녹음 정렬
- 상태: 확정 / P00-05 / 2026-09-16
- 승인: 사용자 추천 조합 선택
- 선택: 날짜 A(한국 시간 고정), 곡명 동률 ①(최신 녹음 우선)
- 관련: R028·R030·R031, X04, P09-03·P18-07
- 공통 사례: [P00-05 사례](../contracts/P00-05-examples.md)

## 날짜와 표시
개인 녹음 목록의 표시 날짜와 기간 필터 시간대는 Asia/Seoul로 고정한다. 기기 시간대 변경으로 목록 날짜·필터 결과를 바꾸지 않는다. 초기 출시에는 시간대 선택 UI를 추가하지 않는다.
recorded_at은 UTC 시각으로 저장한다. 원래 녹음 시각, 당시 시간대 ID·오프셋 및 보정 이력은 기존 설계대로 보존한다. 목록 정렬·필터는 현재 유효한 recorded_at을 사용한다. 과거 원본을 덮어쓰지 않으며 시각 보정 시 관련 정렬·보관 선정도 재계산한다.

- 시작일은 해당 날짜 한국 시간 00:00 이상(포함).
- 종료일은 다음 달력 날짜 한국 시간 00:00 미만(미포함).
- 각 경계를 UTC로 변환해 recorded_at과 비교한다. 문자열 날짜의 부분 비교나 23:59:59로 상한을 만들지 않는다.
- 시작/종료 중 하나만 입력하면 다른 쪽은 제한하지 않는다. 둘 다 비어 있으면 기간 조건 없음.
- 시작일 > 종료일, 유효하지 않은 날짜는 적용을 막고 안내하며 기존 적용 조건을 유지한다.
- 같은 날짜의 시작·종료는 그 하루 전체다. 월말·연말·윤일의 다음 날은 달력 연산으로 구한다.
- 인기곡 API 집계 시간대·휴지통 만료·서명 URL 수명은 이 개인 녹음 필터 계약으로 변경하지 않는다.

## 녹음 목록 정렬
일반 목록은 현재 계정 ACTIVE·SAVED 기록을 대상으로 한다. DRAFT 입력 대기 목록과 휴지통은 별도다. 연결 여부와 파일 유무는 기본 목록에서 배제 조건이 아니다.
K와 UUID 비교는 [D02](D02-sort-order.md)를 따른다. 곡명은 현재 연결 곡 제목이 아니라 녹음 당시 스냅샷 제목을 사용한다.

| 정렬 | 비교 순서 |
|---|---|
| 최신순(기본) | recorded_at 내림차순 → id 오름차순 |
| 오래된순 | recorded_at 오름차순 → id 오름차순 |
| 곡명순 | K(snapshot_title) → recorded_at 내림차순 → id 오름차순 |
| 티어순 | S/A/B/C/D/null 순 → recorded_at 내림차순 → id 오름차순 |

가수·키·버전은 숨은 동률 기준으로 추가하지 않는다. 같은 제목의 최근 연습 기록을 먼저 보여주기 위한 결정이다.

## 필터와 페이지
기존 조건 AND, 태그 한 항목 선택, 초안/적용/취소/초기화 규칙을 유지한다. 날짜·정렬·다른 적용 조건 변경 시 페이지 커서를 초기화한다. UTC 하한/상한과 시간대 계약 버전을 조회 조건에 포함한다. 페이지 안정성의 공통 규칙은 [D04](D04-device-file-filter.md)를 따른다.

## 대안과 검증
현재 기기 시간대 안은 여행 시 날짜 이동이 발생하고, 사용자 선택 시간대 안은 추가 설정이 필요해 채택하지 않는다. 곡명 동률에 가수를 먼저 넣는 안 대신 최신 기록 접근성을 선택했다.
문서 사례 확인은 P00-05 범위이며 실제 날짜 변환·정렬·화면 테스트는 P03·P09·P18에서 수행한다.
