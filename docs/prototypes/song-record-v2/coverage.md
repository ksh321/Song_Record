# 노래기록 UI 시안 02 — 기능 대조표

2026-10-19 사용자의 “앱에 맞게 알아서, 기능 누락 없이 만든 뒤 하나씩 수정” 요청으로 만든 **검토용 초안**이다. Flutter 베타에 적용한 결과나 실제 서버 기능 검증으로 보지 않는다.

- 시작: `index.html` 또는 로컬 미리보기 `http://127.0.0.1:63142/`
- 원본: `docs/reference/b-playlist-ui-v1.11.html`의 화면·샘플 동작을 별도 복사하여 보존했다. 원본 6개는 수정하지 않았다.
- 변경: `preview.css`는 새 시각 규칙, `preview.js`는 화면 구성과 클릭 가능한 보완 흐름이다.
- 화면 안은 제품 제안, 좌우 패널은 시안 검토 도구다. 샘플 기록은 새로고침하면 초기화된다. 화면별 수정 메모와 강조색만 해당 브라우저에 저장된다.
- 실제 음원·개인 계정·API·DB·업로드·결제와 연결하지 않는다. 인증/백업/영구 삭제/내보내기는 상태 화면 시연이며 운영 동작을 수행하지 않는다.

## 초안 01에서 확인한 범위 (이력)

- JavaScript 구문 검사 정상. 전체 목록의 **771개 화면·상태가 렌더링**되고 브라우저 오류 로그 없음. 771개의 실제 기능/네트워크 검사를 했다는 뜻은 아니다.
- TJ/금영 각 3기간 목록 전환과 금영 결과→TJ 검색 연결.
- 곡명 임시 수정, 키 +2 및 여성 모드 전환/적용 뒤 전체 수정 취소: 원래 곡명·원키 유지.
- 플레이리스트 생성, 내 곡 2개 다중 선택/추가, 순서 변경/저장.
- 태그 추가, 녹음 타이머→완료→컨디션/태그 적용→곡 선택→샘플 저장→재생 화면.
- 전체 녹음 태그 필터 적용 결과와 필터 개수.
- 화면별 수정 메모를 입력한 뒤 새로고침에서 유지됨을 확인하고 검사 메모는 지움.
- 하단 선택창의 독립 스크롤과 닫기 표시. 작은 폭에서의 목록/버튼 확인 결과는 검증 기록에 별도 기재.

## 시안 02 — 사용자 PDF와 후속 회신 반영 (2026-10-19)

- 내 곡에 없는 TJ 곡도 플리에 먼저 담는다. ‘플리에만 담긴 곡 · 내 곡 등록 가능’을 표시하고 나중에 등록해도 플리 항목과 순서를 유지한다. 검색/차트는 내 곡 등록·플리 포함 여부를 구분한다. 금영은 기존 TJ 찾기 절차를 유지한다.
- 플리에서 추가할 때 목적 목록에 담는 확인만 표시한다. 휴지통 곡은 설명과 비활성 버튼으로 구분하며 자동 복원창을 열지 않는다. 내 곡 다중 선택·중복 방지·이름 변경·목록에서 제거·목록 삭제를 유지한다.
- 차트 정보와 수집 시각을 화면에서 제거했다. 내 곡 등록의 미정 키를 강조하고 티어 선택을 추가했다.
- 곡 선택 출처를 내 곡/플레이리스트/검색/직접 등록 4개로 표시한다. 녹음 카드는 날짜/시각 위, 곡 정보 왼쪽, 재생·길이와 파일 위치 오른쪽이다. 목록에서 재생 화면으로 진입하고 ⋮로 상세를 연다. 큰 재생 시각·파형·±5초를 표시하고 북마크/위쪽 화살표는 넣지 않았다.
- 컨디션/태그 선택 화면 안에서 분류를 관리할 수 있고 돌아올 때 입력 중 선택·메모를 보존한다. 편집의 샘플 시간대 설명 제거. ‘서버 자동 보관 기준’으로 변경했다.
- 백업 내보내기/백업 가져오기 → 파일 선택 → 가져오기. 별도 사전 검사 버튼 없이 자동 검사·복원 시연으로 연결했다. UUID·체크섬 대신 ‘이미 있는 기록’, ‘이번에 가져오지 않는 항목’과 이유를 설명한다.

### 시안 02 실제 검증

- JavaScript 구문 검사 정상, 브라우저 오류 로그 0. 클릭 검사로 추가된 동적 화면을 포함해 당시 전체 780개 화면·상태 렌더링. 실제 기능 780개를 검증했다는 뜻은 아니다.
- 미등록 곡 → 플리 추가 → 나중 내 곡 B티어 등록 → 곡 수 유지 및 추가됨 비활성. 내 곡 두 곡 다중 추가, 곡 순서 마우스 드래그 저장/키보드 취소, 플레이리스트 목록 키보드 순서 저장 확인.
- 금영 → TJ 검색에서도 플리 목적지 유지. 검색에 ‘내 곡 미등록 · 플리 1개에 담김’ 표시. 휴지통 샘플 곡은 자동 복원 없이 추가 비활성.
- 녹음 곡 선택 4개 경로 진입과 연결, 재생/일시정지·±5초·상세 진입, 태그 추가 관리 왕복 시 저장 전 메모·선택 보존 및 취소 확인.
- 백업 미선택 시 가져오기 비활성, 파일 선택 후 활성, 자동 성공/손상 오류/일부 제외/취소 확인. 차트 6개 조합 목록과 기술 정보 제거 확인.
- 360px 미리보기(테두리 포함, 실제 phone 350px)에서 녹음·플리 가로 넘침 없음. 미정 티어 줄바꿈과 좁은 창의 검토 패널 겹침을 수정했다. 390px 배치도 확인했다.
- 별도 검토: 현재 모델이 기존 초안과 diff·PDF·회신·클릭 결과를 대조. 등록곡 티어, 미연결 표시, 다중 선택, 삭제 보호, 관리 왕복 미저장 값 보존을 확인했다. 다른 검수자/하위 에이전트는 쓰지 않았다.
- 터치 장치에서의 긴 누르기 감각, 실제 파형/음성, 실제 ZIP 검사·복원, Android 큰 글자/하단 시스템 영역은 Flutter 반영 시 검증 대상이다. 시안이 실서비스 동작을 바꾸지는 않는다.

검증 파일과 화면: `.local/workflow/ui-prototype-20261019/revision-02/`. 초안 01 증거는 그대로 보존했다. 이번 결과도 미커밋 검토 시안이며 제품 CI/베타 설치는 해당 없음.


## 시안 03 — 추가 PDF 및 USER-175 회신 (2026-10-19)

사용자 선택: 분류는 선택 목록에서 삭제하되 기존 녹음의 표시는 유지한다. 실제 음원 파형은 베타 반영 때 연결한다. 새 인기차트.pdf의 나머지는 로컬 검토 시안에 반영했다.

- 임의 파랑 계열을 중립 배경/글자색으로 되돌리고 사용자가 선택한 강조색은 유지했다. 차트 행의 내 곡/플리 상태를 제거했고 검색의 상태 표시는 유지한다. 곡 선택은 기존 2열 선택 카드 배치로 복원. 대표 키 전체 대신 ‘미정으로 두기’ 버튼만 강조한다.
- 녹음 카드: 날짜/시각 왼쪽 위, 짧은 재생·길이 버튼 오른쪽 위, 곡 정보 아래. 카드 사이 간격을 줄이고 목록에는 서버 보관 상태 또는 재생 불가만 표시한다.
