# P25-06 제한 음원 보관 검사 준비안

상태: USER139의 10분 검사에서 실제 시험 녹음1개 STORED/COMMITTED 확인 후 조기 잠금 완료. 원본 보존. 원격 재생·음원 포함 백업/복구는 미완료이며 사용자 요청으로 중단했다.

## 변경 범위

현재 AWS 실험 DB와 전용 temporary/final 버킷만 사용한다. 기존 HTTPS 허용 주소는 유지하며 공개 범위를 늘리지 않는다. 자동 작업자·독립 삭제 원장·비용·백업·복원·신선한 실제 객체 대조가 정상이고 수동 잠금이 켜진 경우에만 업로드 검사를 준비한다.

승인 뒤 30분 자동 재잠금을 먼저 등록·확인하고 수동 업로드 잠금 필드만 해제한다. 비용·대조 잠금과 기존 용량·동시 업로드·계정 수 제한은 변경하지 않는다. 해제 도중 오류가 나면 즉시 잠근다. 검사가 빨리 끝나면 30분 전에도 다시 잠근다. 초대·새 계정 생성·개인 계정 삭제·기존 녹음 삭제는 검사에 포함하지 않는다.

## 사용자 검사

기존 별도 베타 앱의 현재 계정에서 개인 대화가 아닌 짧은 시험 소리를 녹음·저장하고 해당 녹음만 고정/보관 신청한다. 서버 사본 완료와 재생을 확인한다. 기기 원본은 지우지 않으며 앱 초기화·삭제·재설치로 원격 재생을 강제하지 않는다. 키나 원음은 채팅으로 보내지 않는다.

시험 음원과 그 정보는 승인된 AWS 실험 서버·전용 R2 저장 공간과 독립 암호화 백업으로 처리된다. 저장량·R2 요청은 기존 무료량과 합산되며 초과 과금 가능성이 있다. AWS Free plan 유지·Paid/Upgrade 금지를 그대로 지킨다.

AI는 파일 내용·원음·제목·메모 대신 업로드 상태·정확한 크기/해시 일치·대조·원장·백업/복구 집계만 확인한다. 실제 폰 재생은 사용자의 확인 또는 실제 기기 검사로 기록한다. 로컬 파일 재생과 원격 파일 재생은 구분한다.

## 백업·복구의 시간 조건

운영 백업은 UTC 하루 한 점을 보존한다. 오늘 이미 만든 빈 음원 복구점을 새 파일이 포함된 것처럼 표시하거나 덮어쓰지 않는다. 실제 음원이 포함된 다음 정규 복구점이 생성된 뒤 별도 임시 DB 복원·해시·디코드를 검사한다. 그 전에는 파일 백업·복구를 미검증으로 남긴다. 원본 DB 대체·새 물리 기기 재생 완료로 확대하지 않는다.

## 실제 전송 연결 보완
후속 녹음 수정/티어/연결 응답은 저장 시 확정한 file 명세를 유지한다. 앱은 유효한 명세와 기존 baseline의 불변성을 검증한다. PUT 성공 뒤 UPLOADED를 영속 저장하고 attempt UUID를 고정 멱등 키로 complete를 요청한다. 응답 유실·재시작은 PUT 없이 완료 요청만 재시도한다. 기존 자동 재시도 예산3회와 계정/claim 보호를 유지하며 202 VERIFYING은 저장 완료로 표시하지 않는다. 새 DB 스키마나 원본 삭제는 없다.
