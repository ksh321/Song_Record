# P00-05 공통 입력과 기대 결과
- 버전: 1.0 / 2026-09-16
- 결정: [D02](../decisions/D02-sort-order.md), [D03](../decisions/D03-date-boundaries.md), [D04](../decisions/D04-device-file-filter.md)
- 아래는 실행 결과가 아닌 테스트 계약이다. P00-08에서 기계 판독 fixture로 통합하고 P03·P07·P08·P09·P14·P18에서 실행한다.
- 예시의 id1/id2는 각각 00000000-0000-4000-8000-000000000001 / 00000000-0000-4000-8000-000000000002이며 뒤 숫자에 따라 확장한다.

## 기기 파일과 복합 필터
F01~F07의 데이터는 현재 계정 ACTIVE SAVED, 같은 메타 조건을 만족한다. P=PRESENT, A=ABSENT, U=UNKNOWN.
공통 입력: r1=(P,false,false), r2=(A,true,false), r3=(P,true,false), r4=(A,false,false), r5=(U,false,false), r6=(P,false,true). 괄호는 (L,S,Q).

| ID | 선택/상황 | 기대 |
|---|---|---|
| F01 | 전체 | r1~r6 메타정보 모두 표시 |
| F02 | 이 기기에만 있음 | 확인된 r1,r6; r5 미확인 안내, 최종 전체 개수 확정 금지 |
| F03 | 서버에 보관됨 | r2 |
| F04 | 이 기기와 서버에 있음 | r3 |
| F05 | 현재 기기에 파일 없음 | 확인된 r4; r5를 없음으로 포함하지 않음 |
| F06 | 용량 부족 | r6, 위치 조건과 별도 |
| F07 | r5 확인 결과 ABSENT | 파일 없음 r4,r5, 정확한 개수 2로 갱신 |
| F08 | 다른 기기에만 파일 보고 있음, 현재 기기는 ABSENT, 서버 STORED 아님 | 현재 기기 PRESENT 아님; 모든 기기에서 파일 소실이라고 단정 금지 |
| F09 | 최초 메타 동기화 일부만 완료 | 잠정 결과·동기화 중 표시, 최종 0건 판정 금지 |
| F10 | 파일 검사 권한/I/O 실패 | UNKNOWN 유지·확인 불가 안내, ABSENT로 처리 금지 |
| F11 | 필터 초안 변경 후 취소 | 기존 목록·개수·cursor 유지 |
| F12 | 초기화 후 적용 | 모든 조건 해제·첫 페이지부터 다시 조회 |
| F13 | 반음=0 AND 버전=MR AND 태그=t1 | 세 조건 모두 만족해야 포함. 반음 0은 조건 없음이 아님 |
| F14 | 계정 A의 파일 경로, 계정 B 로그인 | B의 기기 파일 PRESENT 근거로 사용 불가 |
| F15 | 오프라인 서버 캐시 STORED | 마지막 동기화 기준임을 표시, 실시간 서버 사본 확인 완료로 표시 금지 |
