# 첫 출시 범위 밖의 후속 기능

P25-08 / R003 / 2026-10-16. 아래는 아이디어·별도 기획 대상으로만 보존하며 현재 실행 승인이나 구현 약속이 아니다. 원본 작업 ID를 임의로 새로 배정하지 않는다.

| 후속 범위 | 별도 계획에서 정할 것 |
|---|---|
| 유료 결제·구독·추가 용량 판매 | 요금/환불/플랫폼 결제·서버 권한·이용조건·비용/보안 검증. 현재 결제 구현·유료 전환 없음 |
| 음성 분석·추천 | 목적·처리 위치·외부 전송/보관·동의·비용·정확도/삭제 검증 |
| 공개 피드·공유 링크·공동 편집 | 공개 범위·접근/취소·계정 격리·개인정보·권리·동시성 검증 |
| 개인 드라이브 자동 백업 | 제공자 권한·복구·삭제/외부 사본 책임·비용·동의 |
| 전용 오늘 기능 | 기존 녹음/곡/태그·정렬 기능과 구분되는 요구와 UI·데이터 계약 |

유료 도입 전 제공자 자료의 저장·캐시·재표시 조건을 확인한다는 사용자 결정은 보존한다. 무료 개발 계속 승인이 제공자 허가 확보의 근거는 아니다. M4A/ZIP 내보내기와 서버 선택 보관 등 현재 기능은 위 후속 기능과 별개다.

출시 전 미실행 검증은 후속 기능 아이디어와 섞지 않고 [현재 출시 상태](../verification/P25-08-release-validation.md)에 둔다. 새 기능 착수는 별도 사용자 범위 확정·계획/완료기준·권한/비용 검토 후 진행한다.
