# P25-04 곡 등록·차트 끝 오류 보완 반영안

사용자 요청: 검색/차트 후보의 ‘이 TJ 곡 선택’을 ‘곡 선택’으로 변경하고 중앙 팝업으로 표시. 내 곡 등록 때 대표 키·곡 티어 선택, 메모 바로 아래 어울리는 곡 체크. 차트 마지막 곡 뒤 오류 영역과 추가 스크롤 제거.

## 검증한 변경

- 검색·차트는 공통 중앙 Dialog로 후보 확인. TJ 증명·금영→TJ 조회·진입 목적·계정/요청 유효성·취소 무변경은 보존.
- 기존 키/티어 선택기를 등록 화면에 연결하고 동결된 재시도 요청에도 같은 값을 유지. 기존 DB 열을 사용하며 신규 스키마/마이그레이션은 없음. API 등록 허용 필드·SQL 삽입에 대표 키 모드/반음 쌍을 추가, null/미정 및 원키 -3를 허용하고 불완전 쌍·범위/형식 오류는400.
- 실제 폰의 차트100위 뒤 오류 로그는 ExpansibleState가 PageStorage의 double 스크롤 위치를 bool 펼침 상태로 읽은 타입 오류. 출처 접기 영역의 고유 저장 키를 추가하고 상단으로 이동, 목록은 마지막 곡에서 끝나며 ClampingScrollPhysics와 overscroll 비활성화 적용.
- HTML 직접/TJ 등록에 같은 항목과 메모 아래 하트, 입력 보존·선택값 등록을 반영. 후보 팝업은 휴대폰 시안 중심 오차0px로 확인.
