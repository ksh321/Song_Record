## 실행 범위

- 현재 서버 스키마32에서 V33으로 변경한다. song/recording의 키 CHECK 두 개만 교체하여 ORIGINAL도 -12~12를 허용한다. 기존 행·키 값·하트·플리 아이콘은 보존한다. V2/V3 적용 이력은 변경하지 않는다.
- 기존 API·작업자 이미지만 교체하고 잠시 재시작한다. DB 컨테이너/볼륨·계정/녹음·방화벽·로그인 설정·결제 설정·업로드 잠금은 유지한다.
- 새 베타는 같은 서명과 패키지로 데이터 보존 업데이트한다. 막힌 곡 PATCH는 현재 계정의 기존 400 VALIDATION_FAILED·원곡 기준 비영 반음 값·보존된 PATCH 원문이 확인되는 경우만 동기화 화면의 재시도로 다시 보낸다. 요청 ID/본문/시도 횟수/자동 예산은 초기화하지 않는다. 다른 실패·삭제 요청은 해제하지 않는다.
- 하트 서버 저장과 기존 키 보존, 플리 연속 수정·화면 제목을 실제 설치본에서 확인한다. 시험 표시 변경은 원래 값으로 복구한다. 새 녹음·업로드 잠금 해제는 없다.

## 실행 전후 보호

- 실행 전 현재 이미지·설정 해시·스키마32·모든 서비스 healthy, 작업 대기/실행0·개인 삭제 대기0·업로드 잠금 및 26시간 이내 암호화 백업 성공을 확인한다. 조건이 다르면 적용하지 않는다.
- 기존 계정/곡/플리/녹음 수·용량 및 키/하트/아이콘의 내부 비교 지문이 전후 같아야 한다. 원본 값·토큰은 출력하지 않는다.
